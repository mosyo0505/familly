# 💝 Family Space - 우리 가족 홈페이지

이 프로젝트는 우리 가족만의 소중한 추억과 이야기를 보관하고 소통할 수 있는 따뜻하고 아름다운 웹 공간입니다.

## 🌟 주요 기능

1. **따뜻하고 감성적인 디자인**: 웜/코지 테마와 다크 모드 전환을 제공하며, 부드러운 글래스모피즘(Glassmorphism) 스타일을 적용했습니다.
2. **가족 구성원 소개**: 각 구성원의 특징, 역할, 해시태그를 보여주며 '좋아요(❤️)'를 누를 수 있습니다.
3. **추억 갤러리**: 카테고리별(여행, 일상, 기념일) 필터링이 가능하며, 클릭 시 슬라이드가 지원되는 풀스크린 뷰어(Lightbox)가 열립니다.
4. **가족 D-Day & 일정**: 다음 다가오는 기념일(생일, 결혼기념일 등)까지 남은 일수를 실시간으로 계산해 D-day로 보여줍니다.
5. **롤링 페이퍼 (방명록)**: 브라우저 저장소(`localStorage`)를 활용해 새로고침을 해도 작성한 롤링 페이퍼가 지워지지 않고 보존됩니다.

## 💻 로컬에서 실행 방법

이 프로젝트는 순수 HTML, CSS, JavaScript로 구현되어 있어 별도의 복잡한 설치 과정 없이 바로 실행할 수 있습니다.

### 방법 1. 웹 브라우저에서 직접 열기
- [index.html](index.html) 파일을 마우스 더블 클릭하여 크롬, 사파리, 엣지 등 원하는 웹 브라우저로 엽니다.

### 방법 2. 로컬 개발 서버 실행 (추천)
브라우저 환경에 따라 로컬 이미지나 폰트가 더 안정적으로 로드되도록 로컬 웹 서버를 띄워 실행하는 것이 좋습니다.

**Python이 설치되어 있는 경우:**
터미널에서 이 폴더로 이동한 후 아래 명령을 실행합니다.
```bash
python3 -m http.server 8000
```
이후 브라우저에서 `http://localhost:8000`으로 접속합니다.

## 🌐 GitHub Pages를 통한 무료 웹 호스팅 방법

GitHub 저장소(`mosyo0505/familly`)를 사용하여 전 세계 어디서나 가족들이 모바일이나 PC로 접속할 수 있도록 무료로 홈페이지를 띄울 수 있습니다.

1. 이 프로젝트의 모든 파일(`index.html`, `index.css`, `index.js`, `images/`)을 깃허브 저장소의 `main` 브랜치에 커밋하고 푸시합니다.
2. GitHub 저장소 페이지(`https://github.com/mosyo0505/familly`)로 이동합니다.
3. 상단 메뉴의 **Settings** -> 왼쪽 사이드바의 **Pages** 메뉴를 클릭합니다.
4. **Build and deployment** 섹션의 Source를 `Deploy from a branch`로 설정합니다.
5. **Branch** 항목에서 `main` 브랜치를 선택하고 폴더를 `/ (root)`로 지정한 뒤 **Save**를 누릅니다.
6. 약 1~2분 뒤, 상단에 생성되는 링크(예: `https://mosyo0505.github.io/familly/`)를 클릭하면 전 세계 어디서든 가족들과 공유할 수 있는 실시간 홈페이지가 완성됩니다!
