# Grandparent's Special Gender Reveal Web Application 🎁👦💙

사랑하는 부모님(할아버지 & 할머니)께 손주의 성별이 **남아(왕자님)👦**라는 기쁜 소식을 전하기 위해 제작된 감동적이고 인터랙티브한 모바일 프리미엄 젠더리빌 웹 애플리케이션입니다.

## 🌟 주요 특징 (Key Features)

1. **감동적인 브랜딩 & 비주얼 디자인**
   - 따뜻하고 품격 있는 파스텔톤 글래스모피즘(Glassmorphism) 및 고급스러운 타이포그래피.
   - 고화질 젠더리빌 커스텀 아트워크 및 베이비 왕자님 일러스트 내장.

2. **부모님의 예측 투표 (Guess Game)**
   - "손주가 공주일까요, 왕자일까요?" 사전 예측 클릭 기능 및 센스 있는 응원 메시지.

3. **3가지 다양한 인터랙티브 성별 공개 방식 (Reveal Experiences)**
   - 🎁 **선물상자 열기**: 터치 시 상자 리본이 부드럽게 열리며 성별 공개.
   - 🎈 **풍선 터뜨리기**: 3번 콕콕 터뜨리면 팡! 하고 성별 터지는 인터랙션.
   - 🪙 **복권 긁기**: 동전으로 은색 판을 구석구석 긁어 성별 확인.

4. **하이라이트 성별 공개 & 사운드 / 축하 폭죽 효과**
   - Web Audio API 기반의 오디오 합성기 (별도 음악 파일 다운로드 없이 팡파르 및 팝 효과음 즉시 재생).
   - Canvas Confetti를 활용한 찬란한 골드 & 스카이블루 축하 폭죽 애니메이션.

5. **손주가 할아버지, 할머니께 전하는 감동 편지 (Heartfelt Letter)**
   - 아기의 시선에서 전하는 따뜻한 메시지 카드.

6. **사진 갤러리 & 방명록 (Gallery & Guestbook)**
   - 아기의 첫 순간들 폴라로이드 카운트다운.
   - 할아버지, 할머니의 사랑이 담긴 축복의 한마디 남기기 (로컬 저장소 자동 연동).

7. **카카오톡 및 모바일 웹뷰 공유 최적화**
   - 모바일 화면 비율 완벽 대응 및 링크 복사 / 공유 지원.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism, CSS Grid/Flexbox), JavaScript (ES6+)
- **Visuals**: Generated Canvas Confetti, Custom Generated Visual Assets
- **Audio**: Web Audio API Sound Synthesizer
- **Git Repository**: `https://github.com/mosyo0505/familly.git`
